# Cascadia Stats

Public stats site for our home Cascadia board-game group: game log, leaderboard, player pages and insights.
Plain HTML/CSS/JS with no build step; Chart.js is vendored in `vendor/`.

## Update the data
Scores live in `data/games.json` (generated by `data/build.py` from hand transcriptions of the paper scorecards).
Display names live in `data/players.json`.

```
cd data
python3 build.py                        # only if you edited build.py
SITE_DIR=.. python3 make_site_data.py   # rewrites ../data.js and ../data.json
```

Preview: `python3 -m http.server 8765` in the repo root.
